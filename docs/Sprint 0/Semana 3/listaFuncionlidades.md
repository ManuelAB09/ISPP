# Lista de Funcionalidades con Prioridad

# MVP:

## 1. Autenticación y Gestión de Cuenta

| Funcionalidad | Descripción | Prioridad |
|---------------|-------------|-----------|
| Registro con email y contraseña | Permite a los usuarios crear una cuenta mediante email y contraseña. |  |
| Inicio y cierre de sesión | Autenticación segura y posibilidad de cerrar sesión en cualquier momento. |  |
| Cambio de contraseña | El usuario puede modificar su contraseña desde la configuración. |  |
| Eliminación de cuenta | Permite eliminar permanentemente la cuenta del usuario. |  |
| Edición de perfil | Los usuarios pueden modificar su información personal (foto, bio, datos básicos). |  |
| Ver perfiles de otros usuarios | Permite visualizar perfiles públicos de otros miembros. | |
| Configuración de cuenta | Sección centralizada para ajustes de seguridad, notificaciones y privacidad. |  |
| Control de visibilidad del perfil | Permite decidir si el perfil aparece en listados públicos. |  |

---

## 2. Perfil de Profesor y Verificación

| Funcionalidad | Descripción | Prioridad |
|---------------|-------------|-----------|
| Crear/editar perfil de profesor | Permite añadir especialidades, tarifas y disponibilidad. |  |
| Solicitud de verificación de profesor | Los profesores pueden pagar para aparecer destacados con insignia "Verificado". |  |
| Listado de profesores verificados | Sección destacada con profesores verificados y acceso a contacto directo. |  |
| Pago para verificación/promoción | Flujo de pago para destacar el perfil profesional. |  |

---

## 3. Comunidades

| Funcionalidad | Descripción | Prioridad |
|---------------|-------------|-----------|
| Crear comunidad de estudio | Cualquier usuario puede crear una comunidad. |  |
| Comunidad pública o privada | El creador decide el tipo de acceso. |  |
| Límite de comunidades gratuitas (máx. 3) | Restricción para usuarios free. |  |
| Límites de aforo según tipo y plan | Comunidades gratuitas tienen límite; premium amplían capacidad. |  |
| Explorar comunidades públicas | Sección para descubrir comunidades abiertas. |  |
| Solicitud de acceso a comunidades privadas | Los usuarios pueden pedir acceso. | |
| Unirse a comunidades públicas | Acceso directo sin aprobación previa. |  |
| Gestión de solicitudes | El admin puede aceptar o rechazar solicitudes. |  |
| Expulsar miembros | El administrador puede eliminar usuarios. |  |
| Salir voluntariamente de comunidad | Cualquier miembro puede abandonar el grupo. |  |
| Transferencia de administración | Si el admin abandona, debe designar sucesor. |  |
| Eliminar comunidad | El administrador puede borrar completamente la comunidad. |  |
| Definir categorías internas | Organización del contenido dentro de la comunidad. |  |
| Conversión a comunidad premium | Permite ampliar aforo y desbloquear funciones adicionales. |  |

---

## 4. Chat y Comunicación

| Funcionalidad | Descripción | Prioridad |
|---------------|-------------|-----------|
| Chat en tiempo real | Mensajería instantánea dentro de cada comunidad. |  |
| Adjuntar archivos limitados | Permite compartir archivos en eventos o mensajes (sin repositorio propio completo). |  |
| Enlazar recursos externos | Permite compartir enlaces de Classroom, Drive, YouTube u otras URLs. |  |

---

## 5. Eventos de Estudio

| Funcionalidad | Descripción | Prioridad |
|---------------|-------------|-----------|
| Crear eventos de estudio | Los miembros pueden organizar eventos dentro de la comunidad. |  |
| Eventos públicos o privados | Independiente de la visibilidad de la comunidad. |  |
| Información completa del evento | Incluye título, descripción, fecha, hora, ubicación y aforo. |  |
| Especificar materiales necesarios | Posibilidad de indicar qué llevar al evento. |  |
| Confirmar asistencia | Los usuarios pueden apuntarse al evento. |  |
| Cancelar asistencia | Posibilidad de desconfirmar asistencia. |  |
| Lista de asistentes | Visualización de participantes confirmados. |  |
| Modificar evento | El creador puede editar detalles. |  |
| Cancelar evento | El organizador puede eliminar el evento. |  |
| Control automático de aforo | El sistema bloquea inscripciones al alcanzar el límite. |  |
| Visibilidad en mapa | Los organizadores pueden marcar si el evento aparece en el mapa (en comunidades públicas siempre visible). |  |

## 8. Contratación de Profesores y Pagos

| Funcionalidad | Descripción | Prioridad |
|---------------|-------------|-----------|
| Contratar profesor desde la plataforma | Grupos pueden contratar profesores directamente. |  |
| Gestión de pagos asociados | Control del pago dentro de la plataforma. |  |
| Pago a profesores con comisión | La plataforma aplica comisión y registra transacciones. |  |
| Integración con pasarela de pago (Stripe o similar) | Procesamiento seguro de pagos online. |  |
| Proceso de pago para plan premium individual | Permite suscripción premium para usuarios. |  |

| Cancelación de suscripción | El usuario puede cancelar su plan en cualquier momento. |  |
| Planes institucionales para academias | Oferta especial para instituciones educativas. |  |
| Planes reducidos para academias | Versiones premium con condiciones especiales. |  |

## Funcionalidades Extra

## 1. Sistema de Puntuación y Ranking

| Funcionalidad | Descripción | Prioridad |
|---------------|-------------|-----------|
| Sistema de puntuación de profesores | Los alumnos pueden valorar a los profesores tras cada clase o tutoría. Las valoraciones generan niveles de desempeño (principiante, avanzado, experto). |  |
| Ranking de usuarios | Cada usuario tiene un ranking dentro de su comunidad según participación en chats, cuestionarios y eventos. |  |
| Ranking de cuestionarios | Los resultados de los cuestionarios pueden ser utilizados para clasificar a los participantes. |  |

## 2. Gestión de Contenidos y Cuestionarios

| Funcionalidad | Descripción | Prioridad |
|---------------|-------------|-----------|
| Creación de cuestionarios con IA | Generación automática de cuestionarios por tema usando IA. |  |
| Creación de cuestionarios de forma manual | Generación automática de cuestionarios por tema de forma manual ya sea por un alumno o por el profesor. |  |
| Grabación de sesiones | Guardado de sesiones de estudio para revisión o subida a Google Classroom. |  |
| Seguimiento de progreso y feedback | Visualización del avance de cada alumno y retroalimentación personalizada. |  |
| Perfil del profesor con calendario | Visualización de disponibilidad y clases reservadas. |  |
| Reserva de clases | Los alumnos pueden reservar clases directamente desde la plataforma. |  |
| Mensajería con profesores | Comunicación directa para confirmar reservas o resolver dudas. |  |
| Chatbot de búsqueda de profesores | Asistente inteligente para encontrar profesores según tema. |  |
| Tutorías programadas | Organización de sesiones individuales o grupales con profesores. |  |

## 6. Comunidades

|---------------|-------------|-----------|
