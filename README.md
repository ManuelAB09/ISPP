## 📚 Descripción

Aplicación para crear y gestionar comunidades de estudio, donde los usuarios pueden formar grupos de asignaturas de cualquier curso para reunirse y abordar la asignatura, compartir recursos y subir vídeos de reuniones.

## 🛠️ Tecnologías
- **Backend:** Java, Spring Boot, Maven
- **Frontend:** React 

## 📦 Estructura del proyecto
- `/backend` - API y lógica de negocio
- `/frontend` - Aplicación móvil y web
- `/docs` - Documentación
