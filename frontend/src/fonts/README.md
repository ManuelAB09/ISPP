# Fuentes (Fonts)

## Descripción

Esta carpeta contiene los **archivos de fuentes tipográficas** que se utilizarán en la aplicación. Centralizar las fuentes en esta carpeta permite mantener un control sobre los recursos tipográficos del proyecto y facilita su gestión y actualización.

## Tipos de Archivos de Fuentes

Los formatos más comunes que se pueden almacenar aquí son:

- **`.woff`** / **`.woff2`** - Web Open Font Format (recomendado para web, mejor compresión)
- **`.ttf`** - TrueType Font
- **`.otf`** - OpenType Font
- **`.eot`** - Embedded OpenType (para navegadores antiguos)
