# Static (Recursos Estáticos)

## Descripción

Esta carpeta contiene los **recursos estáticos** de la aplicación, incluyendo imágenes, archivos SVG, iconos y otros elementos multimedia que se utilizan en la interfaz de usuario.

## Tipos de Recursos

Los archivos que se pueden almacenar en esta carpeta incluyen:

- **Imágenes**: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`
- **Vectores**: `.svg` (iconos, logos, ilustraciones)
- **Iconos**: Archivos de iconos en diferentes formatos
- **Ilustraciones**: Gráficos decorativos o informativos
- **Logos**: Logo de la aplicación y marcas relacionadas
- **Otros**: Cualquier recurso multimedia estático

## Estructura Recomendada

```
static/
  ├── images/
  │   ├── backgrounds/
  │   ├── avatars/
  │   └── banners/
  ├── icons/
  │   ├── social/
  │   └── ui/
  ├── logos/
  │   ├── logo.svg
  │   ├── logo-dark.svg
  │   └── logo-light.svg
  └── README.md
```
