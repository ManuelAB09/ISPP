# Utils (Utilidades)

## Descripción

Esta carpeta contiene **funciones utilitarias** que se utilizan en múltiples partes de la aplicación. Son funciones auxiliares para el manejo y procesamiento de datos, como parseos, validaciones, formateos y transformaciones.

## Propósito

Las funciones utilitarias permiten:

- **Reutilización de código**: Código común centralizado en un solo lugar
- **Manejo de datos**: Parseo, formateo y transformación de información
- **Validaciones**: Verificación de datos y formato de entrada
- **Formateo**: Conversión de fechas, números, textos, etc.
- **Operaciones comunes**: Funciones auxiliares que se usan frecuentemente

## Tipos de Funciones Comunes

- **Parseo de datos**: Conversión entre formatos (JSON, strings, objetos)
- **Validaciones**: Validación de emails, teléfonos, formularios, etc.
- **Formateo**: Fechas, moneda, números, textos
- **Transformaciones**: Manipulación de arrays, objetos y estructuras de datos
- **Cálculos**: Operaciones matemáticas o lógicas reutilizables
- **Helpers**: Funciones auxiliares generales

## Estructura de la Carpeta

```
utils/

  ├── formatUtils.js       # Funciones de formateo
  ├── validationUtils.js   # Funciones de validación
```
